# 霓虹炼金场 · Neon Alchemy Arena

霓虹炼金主题的离线生存肉鸽小游戏。当前版本 **V39**：十关主线，每关40波与三场首领战；23种基础技能、9组合体、15种催化道具，以及可同时装配的12件局外装备。

## 开始游戏

下载仓库ZIP并完整解压，用现代浏览器打开 `dist/index.html`。无需安装依赖、编译或自备服务器；保留 `core.js`、`game.js`、`style.css` 与入口在同一目录。

- WASD / 方向键移动，自动攻击；手机可触控移动。
- 开局或暂停选择“清爽 / 标准 / 炫酷”特效。
- 用“保存/读取”导出完整进度；升级版本或换设备前请保存文件。本机自动续玩不是云存档，不会在GitHub上传玩家存档。
- 详细操作见 [离线游玩说明](docs/离线游玩说明.txt)。

## V39 更新

- 保持所有技能强度与机制不变，增强陨星、火箭、离子连锁、星环棱炮、锯轮和投瓶特效。
- 保留减少动态设置、暂停冻结，以及最上层敌人预警。
- 修复底边等不可达区域的能量块与炸弹/磁铁/药丸拾取问题，不提高默认吸附范围。

## 开发与验证

`dist/core.js` 为纯战斗规则，`dist/game.js` 为表现与界面，`dist/app.js` 是旧版留档，不被入口加载。后续维护先读 [开发日志](开发日志.md)。

在Windows PowerShell执行：

```powershell
powershell -File scripts/verify-local.ps1 -Package
```

包含核心规则、模拟DOM/Canvas、压力与存档连续性检查。模拟检查不代表真实浏览器视觉或帧率验收。生成的本地版本压缩包放在 `releases/`，不提交凭据、玩家存档或账号配置。
